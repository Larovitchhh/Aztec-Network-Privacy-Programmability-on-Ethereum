# Aztec-Network-Privacy-Programmability-on-Ethereum
Aztec Network — Privacy &amp; Programmability on Ethereum
1. Introduction

Aztec Network is a privacy-preserving Layer 2 built on Ethereum that enables developers to create encrypted applications (“private smart contracts”). Unlike traditional L2s focused solely on scalability, Aztec combines zero-knowledge proofs with programmability, allowing users to interact with decentralized applications while keeping data encrypted.

Aztec’s goal is straightforward:
bring privacy, confidentiality, and secure computation to Ethereum without sacrificing composability.
